===============================================================================
1. ～と思います (to omou)
===============================================================================
Meaning: think / believe
Structure:
Verb (plain) + と思います
Example:
日本語は難しいと思います。
(I think Japanese is difficult.)

Plain form is nothing but dict form .
===============================================================================
✅ ～でしょう / ～だろう
===============================================================================
Meaning: probably / guess
📘 明日は雨が降るでしょう。
(It will probably rain.)
===============================================================================
✅ ～かもしれません
===============================================================================
Meaning: might / maybe
📘 彼は来ないかもしれません。
(He might not come.)
===============================================================================
✅ ～ようです
===============================================================================
Meaning: it seems / looks like
📘 外は寒いようです。
(It seems cold outside.)

===============================================================================
2. Intention / Plan
===============================================================================
✅ ～つもりです
Meaning: plan / intend
📘 来年日本へ行くつもりです。
(I plan to go to Japan.)
📘 行かないつもりです。
(I don’t plan to go.)
===============================================================================
✅ ～予定です
===============================================================================
Meaning: scheduled to
📘 会議は明日ある予定です。
(The meeting is scheduled for tomorrow.)

===============================================================================
3. Reason / Cause

===============================================================================
✅ ～から
Meaning: because
📘 雨が降るから、行きません。
(Because it’s raining, I won’t go.)

===============================================================================
✅ ～ので
===============================================================================
Meaning: because (softer than から)
📘 忙しいので、先に帰ります。
(Because I’m busy, I’ll go first.)

===============================================================================
🔹 4. Conditions (If / When)
===============================================================================
✅ ～ば
Meaning: if
📘 雨が降れば、行きません。
(If it rains, I won’t go.)
===============================================================================
✅ ～たら
===============================================================================
Meaning: when / if (after something happens)
📘 家に帰ったら、電話します。
(When I get home, I’ll call.)
===============================================================================
✅ ～なら
===============================================================================
Meaning: if it is / speaking of
📘 日本へ行くなら、京都へ行きたいです。
(If you’re going to Japan, I want to go to Kyoto.)
===============================================================================
🔹 5. Contrast / Even If
===============================================================================
✅ ～ても
Meaning: even if / even though
📘 雨が降っても、行きます。
(Even if it rains, I’ll go.)
===============================================================================
✅ ～のに
===============================================================================
Meaning: although / despite
📘 安いのに、おいしいです。
(It’s cheap, but delicious.)
===============================================================================
🔹 6. Reported Speech
===============================================================================
✅ ～と言います / ～と言っていました
Meaning: say / said that
📘 先生はテストがあると言っていました。
(The teacher said there is a test.)
===============================================================================
🔹 7. Change / Result
===============================================================================
✅ ～ようになりました
Meaning: became able to / change occurred
📘 日本語が話せるようになりました。
(I became able to speak Japanese.)
===============================================================================
✅ ～ことになりました
===============================================================================
Meaning: it has been decided that
📘 会議は中止することになりました。
(It has been decided to cancel the meeting.)
===============================================================================
🔹 8. Time / Limit
===============================================================================
✅ ～までに
Meaning: by (deadline)
📘 5時までに来てください。
(Please come by 5 o’clock.)
===============================================================================
🔹 9. Multiple Reasons
===============================================================================
✅ ～し～し
Meaning: and…and (reasons)
📘 安いし、便利です。
(It’s cheap and convenient.)
===============================================================================
🔹 10. Experience / Knowledge
===============================================================================
✅ ～ことがあります
Meaning: have experience of
📘 日本へ行ったことがあります。
(I have been to Japan.)
===============================================================================
✅ ～ことができます
===============================================================================
Meaning: can / able to
📘 日本語が読めることができます。
(I can read Japanese.)
